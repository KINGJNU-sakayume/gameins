# CLAIM DENIED: 사건 #001·#002 프로토타입

`docs/02_CLAIM_DENIED_사건설계_001_002.md`의 두 사건과 `docs/03_CLAIM_DENIED_사건설계_003_초안.md`(요약 기반 초안)의 #003을 실제로 플레이해 보는 정적 HTML 프로토타입입니다. 설계서의 '다음 단계' 1·2번(증거 열람 → 근거 고정 → 판정 제출 → 해설, `undermines`/`corroborates`, 보류, 1일 지연 자료 요청)을 검증합니다.

## 실행

빌드 단계가 없습니다. `prototype/` 폴더를 정적 서버로 엽니다.

```sh
cd prototype && python3 -m http.server 8000
# http://localhost:8000
```

진행 상황은 브라우저 localStorage에 저장됩니다. 사건함의 "진행 기록 지우기"로 처음 상태로 돌아갑니다.

## 파일

| 파일 | 내용 |
|---|---|
| `prototype/cases.js` | 사건 데이터(약관, 청구, 증거, 조사 행동, 채점 기준, 해설)와 콘텐츠 검증기 `validateCases()` |
| `prototype/app.js` | 상태(근무일, 자원 10/일, 근거 고정, 해금, 지연 도착), 해시 라우팅, 채점 |
| `prototype/app.css` | 화면 스타일. 첫 줄 주석에 디자인 결정 기록 |
| `prototype/tokens.css`, `base.css` | 디자인 토큰과 기본 규칙 (Hallmark Formwork 테마 기반) |

## 플레이 경로 예시

- **#001 정답:** E1-1·E1-2·E1-3·E1-4를 근거로 고정 → 지급 320,000원
- **#001 함정:** 구매 영수증(E1-5) 날짜만 보고 기각 → 오답
- **#002 저비용 정답:** 관리사무소 기록 열람(자원 1)으로 E2-8 확보 → E2-2·E2-6·E2-4·E2-8 고정 → 지급 1,150,000원
- **#003 정답:** 계량기 기록 요청(자원 2) + 설비 로그 추출(자원 3) → E3-2·E3-4·E3-10·E3-7 고정 → 지급, 항목별로 재고 원단 보장, 바닥 방수층 보장, 분전반 면책 → 13,100,000원
- **#003 두 함정:** 폭우 기록만 보고 기각 → 오답 / 배관 파열만 보고 세 항목 모두 보장 → 원인 미분리
- **#002 정당한 보류:** 추가 자료 요청(무료, 1일 지연) 후 보류 → 근무 종료 → 다음 날 순찰 일지(E2-7) 도착, 경비원 진술(E2-5)에 불일치 표시

## 디자인

[Hallmark](https://github.com/Nutlope/hallmark) 스킬의 app screen 범위로 만들었습니다. 테마는 Formwork(콘크리트 회색 종이, 검정 잉크, 각진 모서리, 하드 섀도, 안전 주황 한 가지)이고, 시그니처는 고정한 근거가 모이고 제출 시 도장이 찍히는 판정서입니다. `sloplint --scope app --render` 결과 FAIL 0입니다.
