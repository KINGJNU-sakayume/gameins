# 사건 #003 — 지하 창고 침수 (2막 · 원인 분리)

## 0. 이 사건의 역할

| | 내용 |
|---|---|
| 가르치는 능력 | 원인 분리, 항목별 지급, 시각 기록으로 원인의 경계 긋기 |
| 처음 드는 생각 | "폭우니까 면책 → 기각" |
| 두 번째 생각 | "배관이 터졌네 → 전액 지급" |
| 실제 결론 | 항목별 부분 지급 (자기부담금 차감) |
| 핵심 쾌감 | 두 번 뒤집히는 가설 |
| 자원 사용 | 5~10 |

## 1. 가상 약관 (NORTHSTAR 소상공인 재물 손해 담보)

- **보장:** 사업장 내 급배수 설비의 누출로 인한 수침 손해
- **자기부담금:** 청구 1건당 500,000원
- **면책:** 홍수, 폭우 등 사업장 외부에서 유입된 물에 의한 손해
- **효력 기간:** 2026-03-01 ~ 2027-02-28
- **참고 규정:** 손해의 원인이 둘 이상이면 손해 항목별로 원인을 가려 보장되는 부분만 지급한다.

## 2. 실제 사건 (내부 정답, UI 비노출)

2026-07-16 밤부터 폭우가 내렸다. **02:10** 한솔상가 지하 1층 창고 안의 급수 배관 이음부가 파열되어 물이 새기 시작했고, 05:30까지 바닥 수위가 약 18cm에 이르렀다. 이 시점까지 바닥에 놓인 원단 팔레트 하단과 바닥 방수층이 젖었다. **05:35**부터 상가 진입 램프로 빗물이 쏟아져 들어와 06:20 수위가 1.3m에 이르렀고, 벽면 1.2m 높이의 분전반은 이때 잠겼다. 청구인 한도윤은 07:10 출근해 발견했고 같은 날 접수하면서 청구서에 "폭우로 창고가 침수됐다"고 적었다.

## 3. 청구 개요

- 청구인: 한도윤 (한솔상가 지하 1층 B101 창고, 원단 도매)
- 청구 금액: **18,400,000원**

| 손해 항목 | 금액 | 위치 | 원인(내부) | 판정 |
|---|---|---|---|---|
| 재고 원단 하단 팔레트 | 9,600,000 | 바닥 0~20cm | 배관 누수 (02:10~05:30) | 보장 |
| 바닥 방수층 복구 | 4,000,000 | 바닥 전면 | 배관 누수 | 보장 |
| 분전반 교체 | 4,800,000 | 벽면 1.2m | 외부 빗물 (05:35 이후) | 면책 |

## 5. 경쟁 가설

- **H1 (첫 함정):** 폭우로 인한 외부 침수 → 전부 면책 → 기각
- **H2 (두 번째 함정):** 배관 파열이 원인 → 전부 보장 → 전액 지급
- **H3 (정답):** 두 원인이 시각으로 나뉜다. 05:30 이전(수위 18cm 이하)의 손해는 배관, 이후 1.2m 높이의 손해는 빗물 → 항목별 부분 지급

반증 경로:
- H1: E3-7(02:10 사용량 급증) 또는 E3-8(이음부 파열)
- H2: E3-10(05:30 18cm → 06:20 130cm) 그리고 분전반 높이 1.2m (E3-4·E3-3)

## 7. 정당한 판정

- **결정:** 지급 (항목별)
- **지급액:** (9,600,000 + 4,000,000) − 500,000 = **13,100,000원**
- **필수 근거:** E3-2, E3-4, E3-10, 그리고 E3-7 또는 E3-8

## 8. 해설 문구 (골자)

> 폭우는 사실이지만 물이 처음 들어온 원인은 아닙니다. 수도 계량기는 02:10부터 사용량이 급증했고, 수위 센서는 05:30까지 18cm였고, 05:35 빗물이 램프로 들어온 뒤 05:40부터 1.3m까지 올랐습니다. 바닥 높이의 재고 원단과 방수층은 배관 누수로 먼저 젖었으므로 보장되고, 벽면 1.2m의 분전반은 빗물이 들어온 뒤에 잠겼으므로 면책입니다. 보장 항목 13,600,000원에서 자기부담금 500,000원을 빼면 13,100,000원입니다.
